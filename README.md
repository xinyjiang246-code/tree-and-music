# 树与音乐

> **Status: Work in Progress · 仍在进行中**
>
> An unfinished prototype. The "photo → hear it" path works end to end; "return to a place" and "grow into a grove" are still early-stage experiments.
>
> 一个仍在开发中的原型。「照片 → 听见它」主链路完整可跑，「落回地方 → 长成一片」两个阶段还处在实验阶段。

一张树的照片，变成一段可以听的东西。

核心链路：**照片 → 听见它 → 落回地方 → 长成一片**。歌曲是可选的「给它一首歌」，不和照片并排争夺入口。

🔗 **在线预览**：https://xinyjiang246-code.github.io/tree-and-music/

## 怎么跑

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

直接双击 `index.html` 也能看，但语音/音频在 `file://` 下可能被浏览器拦，建议走本地服务器。

## 主路径：照片 → 听见它

拍下来的树被抽成骨架，然后：

- **每个枝梢是一个音**。枝梢越高，音越高（五声音阶，不会难听）
- **树干是不停的低音**，一直铺在底下
- **音符稀疏**（1.5–4 秒一个），每个音都带很长的混响尾

它不会「唱一段旋律」，它是**环境音景**——像站在树底下，风穿过枝条时偶尔响一下。这是刻意的：把树的形状直接映射成旋律，出来一定是随机音，十分钟就想关掉。

每个音响起时，那个枝梢会亮一下，你能听见「是哪一根枝在响」。

### 可选：给它一首歌

照片进来之后，歌曲是可选项，不影响主路径。放一首歌，让频谱驱动这棵树的**光**：

- 低频（鼓、贝斯）→ 整棵树呼吸、光晕变强
- 高频（镲、人声齿音）→ 树冠里的光点闪

它**不改树的形态**：骨架、枝条、长短都是原来那棵，音乐只落在亮度和呼吸上。可以拖入本地 mp3 / m4a / wav；不拖就用内置的合成 loop。

## 延伸的原型

| 文件 | 内容 |
|---|---|
| `index.html` | 主入口：上传照片 → 听见这棵树 |
| `grove.html` | 树丛：多棵树长在一起 |
| `world3d.html` | 世界树：3D 地球上的树 |
| `tree3d.html` | 单树 3D 原型，与 2D 并排对照 |
| `tree-sample.html` | 最小骨架演示 |
| `basins.html` / `geo.html` | 地理与流域的实验页 |

## 目录

```
index.html / app.js / style.css     主链路
melody.js                           枝梢 → 音符 的映射
grove.*  world3d.*  tree3d.*        三个延伸原型
data/                               地理与物种数据（含 2K/4K 陆地图）
vendor/                             three.js 等
tools/                              构建与检查脚本
原型说明.md                          完整的设计与实现笔记（很长，建议先读这个）
```
